# Oficios24 UI Golden Rules (Minimalist v2)

This document defines the minimalist UI/UX standards for the Oficios24 platform. All components and page refactors must adhere to these rules for a professional, high-contrast, and premium aesthetic.

---

## 1. Typography Hierarchy
- **Primary Heading Font**: **Outfit**.
  - Use for: Main page titles, section headings, and job titles.
  - Weight: `font-bold` (avoid Black/Extrabold).
- **UI & Body Font**: **Inter**.
  - Use for: Paragraphs, subtext, buttons, navigation links, and inputs.
  - Weight: `font-medium` or `font-semibold`.
- **Primary Text Color**: `Slate-950` (#020617) - Use for all primary content for maximum contrast.
- **Secondary Text Color**: `Slate-600` (#475569) - Use for descriptions, meta-data, and placeholders.

## 2. Colors & Surfaces
- **Background**: `Slate-50` (#f8fafc).
- **Surfaces**: Pure white (#ffffff).
- **Accent**: Primary Brand Orange for CTA buttons and interactive states only.

## 3. Geometry (Subtle)
- **Border Radius**:
  - **xl (12px)**: Main cards and page containers.
  - **lg (8px)**: Buttons and input fields.
- **Borders**: `Slate-100` or `Slate-200`.

## 4. Inputs & Buttons (Minimalist)
- **Inputs**: Height `h-12`. Font `Montserrat`. Background `Slate-50`.
- **Buttons**: Font `Montserrat`. Weight `font-bold`. Padding `py-2.5 px-6`.

## 5. Shadows
- **Standard**: `shadow-soft` (extremely minimal).
- **Hover**: `shadow-premium` (subtle lift with no aggressive scaling).
